Guia rápido

  1. Fique Online

    Ao entrar, confira se seu status está Online (canto de baixo, na sua foto). Conversa nova só vai para quem está online.

  2. Você vê a sua loja

    Cada atendente vê só as conversas da própria loja. O dono e a esposa veem as duas.

  3. Responda pela conversa

    O cliente recebe no WhatsApp com o seu nome em cima da mensagem. Para anotar algo só para a equipe, use Nota privada.

  4. Terminou? Resolva

    Clique em Resolver. Se o cliente escrever de novo, a conversa aparece outra vez no painel.

O que o sistema faz sozinho

  • Responde a primeira mensagem do cliente com as boas-vindas da loja.
  • Coloca a conversa na equipe da loja certa.
  • No Instagram, pergunta com qual loja o cliente quer falar (1 ou 2).
Área técnica: conectar um número Só para o responsável técnico. Pede a chave do sistema.
Antes de escanear:
  • Use só o chip da loja. Nunca um número pessoal: o histórico inteiro de conversas é copiado para o painel.
  • Desligue as automações das caixas de WhatsApp (painel → Configurações → Automação). Depois de conferir o número, rode scripts/configurar.py para religar.

  2. Toque em ⋮ (ou Configurações) → Dispositivos conectados → Conectar dispositivo.

Se o WhatsApp disser “não foi possível conectar novos dispositivos”, espere alguns segundos e escaneie o próximo código: é uma falha conhecida e passa com novas tentativas.
